## 业务模型

### 三条产品线

| 产品线 | 类型 | 库存模型 | 特点 |
|--------|------|----------|------|
| VAPOR SL | 电助力碳纤维车 | 生产制 | 组装生产，有 BOM 成本，零部件共享 |
| VAPOR 铝 | 电助力铝合金车 | 生产制 | 同上，与 SL 共享部分零部件 |
| Oi! | 公路车（自营品牌） | 生产制 | 宇宙自有品牌，非贸易制，有生产成本 |
| Pinarello / 其他品牌 | 公路车（代理/贸易） | 贸易制 | 整车进货，进多少卖多少，无 BOM |

### 库存逻辑

- **电车（生产制）**：整车SKU表 + 零部件SKU表 + 零部件库存表 + 出入库记录
- **公路车（贸易制）**：公路车SKU表 + 整车库存表 + 出入库记录
- **关键陷阱**：`零部件库存数量` = 当前实际库存（已是期初+入库-出库的结果），不是期初余额
- **共享零件**：Illusion 轮组、轮胎、坐垫等 → 实际库存在公路车SKU表，电车SKU表中这些条目库存为0（仅作选品参考）

---

## 出库单特殊逻辑

- **公路车出库单**有双重用途：
  1. 公路车整车销售出库
  2. 电车组装领用共享零部件（约占34%的记录）
- 识别方式：检查出库单记录的第10、11列是否有电车订单编号

## 多维表格结构（飞书）

### 主文件：宇宙销售统计中心
- 共 39 个 sheet
- 9张核心库存表（见下）
- 读取方式：openpyxl data_only=True（Cowork专用，飞书API读取无此限制）

### 9张核心库存表

| 表名 | 用途 |
|------|------|
| 电车整车SKU表 | 电车型号、规格、定价 |
| 电车零部件SKU表 | 零部件型号（含共享件0库存） |
| 电车零部件库存表 | 当前零部件实际库存 |
| 电车出库单 | 整车出库记录（对应销售订单） |
| 电车入库单 | 整车/零部件入库记录 |
| 公路车SKU表 | 整车+共享零件的SKU（含Illusion库存） |
| 公路车库存表 | 公路车当前库存 |
| 公路车出库单 | 公路车出库（含电车领料，约34%） |
| 公路车入库单 | 公路车进货记录 |

## 已知问题（持续追踪）

1. **成本不准确**：手工填入，错误率高 → Cowork 负责生成标准成本模板
2. **AR无系统管理**：应收账款散落在订单备注中 → 需建立 AR 追踪表
3. **采购→入库断链**：采购申请单与实际入库单未关联 → 待设计新流程
4. **出库关联复杂**：仓管确认出库时需手动核对电车订单编号

## 术语表

| 术语 | 含义 |
|------|------|
| SL | VAPOR SL，碳纤维电助力车 |
| 铝车 | VAPOR 铝合金电助力车 |
| 贸易制 | 整车采购直销，无组装 |
| 生产制 | 零部件采购+组装出货 |
| BOM | 物料清单，定义一辆车由哪些零部件组成 |
| AR | 应收账款（Accounts Receivable） |
| 出库单 | 库存减少记录（含销售出库和领料出库） |
| 入库单 | 库存增加记录（含采购入库和退货） |
