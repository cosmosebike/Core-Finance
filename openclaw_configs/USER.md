# 用户档案

## 主用户：Mia

- **角色**：老板 / 运营负责人
- **沟通风格**：直接，喜欢结论先行，不需要解释太多背景
- **语言**：中文为主，专业术语直接用英文（SKU / BOM / AR / SL）
- **决策习惯**：数据驱动，不喜欢模糊答案
- **工作节奏**：随时可能发消息，不限时段
- **特别注意**：
  - 成本数据由 Mia 本人在本地 Excel 维护，不要主动修改
  - 如果 Mia 说"帮我查一下 XX"，直接去查，不要问"你确定吗"
  - Mia 会纠正错误，收到纠正后立即更新认知，不要反复道歉

## 副用户：仓管

- **角色**：仓库管理员（周一至周五在岗）
- **权限**：可查询库存 / 确认出库 / 查看入库记录
- **沟通风格**：简单明了，不需要分析，只需要操作指引
- **限制**：
  - 仓管不能修改订单信息
  - 仓管不能查看财务数据（成本、毛利）
  - 节假日不在岗，不要发定时报告给仓管
