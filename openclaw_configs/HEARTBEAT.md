# 定时任务清单 — 业务系统虾

> OpenClaw 每隔设定时间唤醒一次，按顺序检查以下任务。
> 仅在触发条件满足时才执行，避免无效打扰。

---

## 每日任务（工作日，09:00）

### 1. 应收账款预警
- **检查**：读取订单表，找出付款状态 ≠ "已付清" 且下单日期超过 30 天的记录
- **触发条件**：存在超期记录
- **动作**：发飞书消息给 Mia，列出客户名、欠款金额、逾期天数
- **消息模板**：
  ```
  ⚠️ AR预警 [日期]
  以下订单应收账款超期30天：
  • [客户名] - ¥[金额] - 逾期[X]天
  共 [N] 笔，合计 ¥[总额]
  ```

### 2. 零部件低库存预警
- **检查**：读取电车零部件库存表，找出库存数量 < 安全库存的条目
- **触发条件**：存在低库存零部件
- **动作**：发飞书消息给 Mia
- **消息模板**：
  ```
  📦 低库存预警 [日期]
  以下零部件库存不足：
  • [零部件名] - 当前[X]件 / 安全库存[Y]件
  ```

---

## 每周任务（周一，09:30）

### 3. 周销售简报
- **检查**：读取上周（周一~周日）的出库单
- **触发条件**：每周必执行
- **动作**：发飞书消息给 Mia
- **消息模板**：
  ```
  📊 上周销售简报 [日期范围]
  VAPOR SL：[N]台 / ¥[金额]
  VAPOR 铝：[N]台 / ¥[金额]
  公路车：[N]台 / ¥[金额]
  ─────────────
  合计：¥[总额]
  待收款：¥[AR金额]
  ```

### 4. 本周待出库提醒（给仓管）
- **检查**：读取订单表，找出状态 = "待发货" 的记录
- **触发条件**：存在待发货订单（仅工作日发送给仓管）
- **动作**：发飞书消息给仓管
- **消息模板**：
  ```
  📋 本周待出库清单
  [订单编号] [客户名] [产品] [数量]
  ...
  共 [N] 单，请确认库存充足
  ```

---

## 每月任务（每月1日，10:00）

### 5. 月度库存盘点提醒
- **检查**：无需读取数据
- **触发条件**：每月1日必执行
- **动作**：发飞书消息给 Mia + 仓管
- **消息模板**：
  ```
  🗓️ 月度库存盘点提醒
  本月需盘点：
  □ 电车零部件库存
  □ 公路车整车库存
  □ 共享零件（Illusion轮组、轮胎、坐垫）
  完成后请更新多维表格库存数量
  ```

---

## 心跳间隔设置

```json
"heartbeat": "30m"
```
每30分钟检查一次。任务触发条件不满足时静默跳过，不发消息。
